# Сервис учета тренировок

## Назначение

Данный проект направлен на разработку сервиса учета тренировок.
Пользователь может записывать свои тренировки, отслеживать прогресс,
анализировать нагрузку и видеть динамику результатов. Система помогает
структурировать информацию о выполненных упражнениях, подходах, весах
и повторениях.

## Целевая аудитория

Основными пользователями данного приложения являются люди, которые
стремятся к здоровому образу жизни и стараются увеличить свою
спортивную активность.

## Предметная область

Проект реализует три связанные сущности:

- **Упражнение** — справочник упражнений (название, рабочая группа
  мышц);
- **Тренировка** — дата, тип (кардио/силовая), длительность и список
  выполненных упражнений (подходы, повторения, рабочий вес);
- **Результат за период времени** — агрегирует тренировки пользователя,
  попавшие в выбранный период (один результат может включать
  множество тренировок).

Бизнес-правила:

- тренировка не может быть создана без хотя бы одного упражнения;
- дата тренировки не может быть в будущем;
- количество подходов и повторений должно быть ≥ 0;
- дата окончания периода результата не может быть раньше даты начала.

## Возможности

- просмотр, поиск и фильтрация упражнений по группе мышц;
- добавление упражнений в справочник;
- создание и отмена тренировок с проверкой бизнес-правил;
- статистика по всем тренировкам (количество, суммарная длительность,
  разбивка по типам);
- формирование результата за произвольный период и просмотр
  статистики конкретно по этому периоду.

## Основные функции

| Функция | Модуль | Назначение |
|---|---|---|
| `add_exercise` | exercises.py | добавить упражнение в справочник |
| `find_exercise` | exercises.py | найти упражнения по подстроке названия |
| `filter_exercises_by_muscle_group` | exercises.py | отобрать упражнения по группе мышц |
| `sort_exercises` | exercises.py | отсортировать упражнения по названию |
| `create_workout` | workouts.py | создать тренировку с проверкой бизнес-правил |
| `cancel_workout` | workouts.py | отменить тренировку |
| `find_workouts_in_period` | workouts.py | отобрать тренировки по периоду дат |
| `get_workout_stats` | workouts.py | статистика по тренировкам |
| `trening_result` | workouts.py | статус тренировки и количество выполненных упражнений (перенесена из ПР1) |
| `reality_task` | workouts.py | подсчёт количества выполненных упражнений (перенесена из ПР1, исправлена ошибка подсчёта) |
| `create_result` | results.py | сформировать результат пользователя за период |
| `find_result_by_id` | results.py | найти результат по id |
| `get_result_stats` | results.py | статистика по тренировкам, входящим в результат |
| `load_*` / `save_*` | storage.py | загрузка и сохранение данных в JSON |
| `input_int` / `input_date` | utils.py | безопасный ввод с обработкой ошибок |

## Структура проекта

Код разделён на модули по смыслу — каждый файл отвечает за свою часть
функциональности:

| Модуль | Назначение |
|---|---|
| `main.py` | точка запуска, меню приложения |
| `exercises.py` | работа со справочником упражнений |
| `workouts.py` | работа с тренировками |
| `results.py` | работа с результатами за период времени |
| `storage.py` | сохранение и загрузка данных (JSON) |
| `utils.py` | безопасный ввод чисел и дат |
| `data/` | JSON-файлы данных (exercises.json, workouts.json, results.json) |
| `tests/` | тесты pytest — по одному файлу на каждую сущность |
| `conftest.py` | пустой файл-маркер корня проекта, нужен pytest, чтобы тесты из tests/ могли импортировать модули из корня без установки проекта как пакета |

## Требования

- Python 3.10+;
- pytest — тестирование;
- flake8 — линтер (проверка стиля и ошибок);
- black — форматтер (автоматическое приведение кода к единому стилю).

Настройки линтера и форматтера согласованы между собой в файле
`.flake8` (max-line-length = 88, что соответствует длине строки по
умолчанию у black; отключены правила E203/W503, конфликтующие с
форматированием black).

Установка зависимостей:

```
pip install -r requirements.txt
```

## Запуск программы

```
python main.py
```

## Запуск тестов

```
pytest
```

Тесты покрывают все три сущности предметной области: test_exercises.py,
test_workouts.py, test_results.py.

## Проверка и форматирование кода

Проверка линтером:

```
flake8
```

Автоматическое форматирование кода:

```
black .
```

Проверка без изменения файлов (например, перед коммитом):

```
black . --check
```
