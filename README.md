# Название проекта 
Сервис учета тренировок
## Назначение 
  
Данный проект направлен на разработку сервиса учета тренировок. Пользователь может записывать свои тренировки, отслеживать прогресс, анализировать нагрузку и видеть динамику результатов. Система помогает структурировать информацию о выполненных упражнениях, подходах, весах и повторениях.
  
## Целевая аудитория 
  
Основными пользователями данного приложения являются люди, которые стремятся к здоровому образу жизни и стараются увеличить свою спортивную активность
  
## Предметная область 
  
Краткое описание предметной области. 
  
## Основные сущности 
  - Пользователь 
  - Тренировка 
  - Упражнения
  - Результат за период времени 
  
## Основные функции 
  - count_task: считает количество выполненных упражнений
  - trening_result: выводит результат тренировки (статус и количество выполненных упражнений)
  
## План развития 
  
На следующих этапах планируется: 
  - разработка веб-приложения;

  - контейнеризация приложения; 
  - настройка CI/CD.
